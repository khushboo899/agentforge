# AgentForge

AgentForge is a terminal-based, LangGraph-orchestrated AI assistant. It combines local PDF retrieval (FAISS), conversation history, current-information research through Groq's supported browser-search tool, safe arithmetic, answer review/retry, and JSONL observability traces.

## Features

- **Intent routing:** deterministic handling for greetings, document questions, current-information requests, and arithmetic.
- **Local PDF RAG:** discovers PDFs in `data/` automatically; no repeated PDF path prompts.
- **Semantic search:** chunks PDFs, embeds them with `sentence-transformers/all-MiniLM-L6-v2`, and persists FAISS indexes under `vectorstore/`.
- **Source references:** retrieval results include the source PDF and human-readable page number.
- **Web research:** attempts current research only when the request needs it; failures are disclosed rather than fabricated.
- **Safe calculator:** evaluates basic arithmetic with a restricted AST, not arbitrary Python code.
- **Conversation memory:** keeps recent turns in the CLI session and persists LangGraph checkpoints in SQLite.
- **Critic/retry:** reviews generated answers when the provider is available; provider failures do not create infinite retry loops.
- **Observability:** JSONL traces record graph spans, latency, token usage when supplied by the provider, tool calls, errors, and summaries.
- **Provider failure handling:** a missing key or rate/quota limit is reported clearly; document retrieval can still provide a fallback answer.

## Requirements

- Python 3.11 or 3.12 recommended.
- A Groq API key for model calls and web research.
- Internet access for installing dependencies and downloading the embedding model on first use.

## Setup (Windows PowerShell)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

Open `.env` and replace `your_groq_api_key` with your own key. Do not share or commit `.env`.

Place your own PDFs in `data/` (a sample PDF is included in the project bundle), then run from the `AgentForge` project directory:

```powershell
python -m app.main
```

Enter `exit` to quit.

## Configuration

| Variable | Purpose | Default |
|---|---|---|
| `GROQ_API_KEY` | API authentication | Required for model/web calls |
| `AGENTFORGE_MODEL` | Model supported by your Groq account | `openai/gpt-oss-120b` |
| `AGENTFORGE_TRACE_DIR` | Trace output directory | `traces/` |
| `AGENTFORGE_DEBUG` | Enable debug diagnostics | `false` |
| `MODEL_INPUT_COST_PER_1M` | Optional input price for cost estimates | `0` |
| `MODEL_OUTPUT_COST_PER_1M` | Optional output price for cost estimates | `0` |

Cost estimates are only meaningful when you set rates matching your provider and model. Token counts may be unavailable if a provider response omits usage metadata.

## Tests

After installing dependencies, run the offline smoke tests:

```powershell
python -m unittest discover -s tests -v
```

These tests do not call the LLM or web search. The first real PDF query may take longer because the embedding model and a per-PDF FAISS index are created the first time.

## Runtime files

- `data/`: trusted local PDF knowledge sources.
- `vectorstore/`: generated local FAISS indexes; do not commit these.
- `checkpoints.sqlite*`: local LangGraph persistence; do not commit these.
- `traces/`: JSONL request traces; review before sharing because traces can contain user prompts and retrieved document snippets.

## Limitations

- Web research depends on Groq model/tool availability, network access, provider quotas, and account entitlements.
- The critic is a model-based quality check, not a guarantee of factual correctness.
- PDF retrieval quality depends on the document's text extraction and embedding similarity; scanned PDFs may require OCR.
- This is a local CLI project, not yet a hosted multi-user service. Do not expose it publicly without authentication, request limits, secrets management, and privacy controls.

## Security

Never commit `.env`, API keys, virtual environments, local databases, vector stores, or traces. If an API key was ever committed or included in a shared archive, rotate it and clean it from repository history. FAISS indexes use local serialized metadata; only load indexes generated by this application from trusted files.
